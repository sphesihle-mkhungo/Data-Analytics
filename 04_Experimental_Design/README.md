# Experimental Design

## Overview

Experimental design provides the foundation for reliable scientific research. This module introduces the principles and methods used to design agricultural, ecological, and biological experiments that produce valid and reproducible results.

---

## Learning Objectives

By the end of this module you will be able to:

- Understand the principles of experimental design
- Identify appropriate experimental designs for different research questions
- Recognize sources of experimental variation
- Select suitable statistical analyses for each design
- Interpret experimental results correctly

---

## Topics

- Principles of Experimental Design
- Completely Randomized Design (CRD)
- Randomized Complete Block Design (RCBD)
- Split-Plot Design
- Factorial Experiments
- Latin Square Design
- Repeated Measures Design
- Sampling Strategies
- Randomization
- Replication
- Blocking
