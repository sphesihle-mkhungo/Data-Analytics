# Exploratory Data Analysis (EDA)

## Overview

Exploratory Data Analysis (EDA) is the process of understanding a dataset before performing formal statistical analyses. It helps identify trends, patterns, relationships, anomalies, and potential data quality issues.

---

## Learning Objectives

By the end of this module you will be able to:

- Understand the structure of a dataset
- Summarize variables
- Explore distributions
- Investigate relationships between variables
- Detect unusual observations
- Produce informative summary tables

---

## Topics

- Dataset Structure
- Summary Statistics

- Correlation Exploration
