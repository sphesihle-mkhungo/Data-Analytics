# Statistical Modelling

## Overview

Statistical modelling is the process of using mathematical and statistical techniques to understand relationships within data, test scientific hypotheses, and support evidence-based decision making. 
This module focuses on the statistical methods commonly used in agricultural, ecological, and biological research.

---

## Learning Objectives

By the end of this module you will be able to:

- Select appropriate statistical models for different research questions
- Check model assumptions
- Interpret model outputs
- Compare competing models
- Perform post-hoc analyses
- Communicate statistical results effectively
