# Module 1: Data Cleaning

## Overview

Data cleaning is the foundation of every successful data analysis project.

Whether you are analysing ecological surveys, clinical trials, financial records, agricultural experiments, or environmental monitoring data, the quality of your conclusions depends on the quality of your data.

This module introduces the principles, techniques, and best practices required to transform raw data into reliable, analysis-ready datasets using reproducible workflows in R and Python.

---

## Learning Outcomes

By the end of this module you will be able to:

- Explain the importance of data cleaning.
- Identify common data quality problems.
- Detect missing values and inconsistencies.
- Handle duplicate observations.
- Identify and investigate outliers.
- Standardise variables and data types.
- Prepare reproducible data cleaning workflows.
- Document every transformation performed on a dataset.
