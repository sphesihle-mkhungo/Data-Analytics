# Module 1: Data Cleaning

## Overview

Data cleaning is the foundation of every data analysis project.

Before statistical analyses, machine learning models, dashboards, or visualisations can produce meaningful results, the underlying data must be accurate, complete, and consistent. Poor-quality data can lead to misleading conclusions, incorrect decisions, and unreliable research outcomes.

This module introduces the principles, methods, and best practices for preparing high-quality datasets for analysis using reproducible workflows in both **R** and **Python**.

Although the examples in this module are drawn mainly from scientific research—including agriculture, ecology, environmental science, and biological studies—the concepts apply to data analysis in any discipline.

---

# Learning Objectives

By the end of this module, you should be able to:

- Explain the importance of data cleaning.
- Identify common data quality problems.
- Detect and manage missing values.
- Identify duplicate observations.
- Detect potential outliers.
- Standardise variable names and data types.
- Validate datasets before analysis.
- Document data cleaning decisions.
- Produce reproducible data cleaning workflows.
