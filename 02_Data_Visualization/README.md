# Data Visualization

#Overview

Data visualization is one of the most important aspects of data analytics. It allows us to visually inspect data at a glance, in order to observe patterns and trends.
This module demonstrates how to create clear, informative, and publication-quality visualizations for agricultural and ecological data using R.

#Learning Objectives
By the end we should be able to:

-Format data appropriately
-Prepare data for visualization
-Choose the correct method of visualization
-Identify data structure and distribution
-Identify outliers
-Identify patterns and trends


Topics that will be covered include:

- Scatter plots
- Boxplots
- Histograms
- Bar charts
- Line graphs
- Correlation plots
- PCA biplots
- Publication-ready figures using ggplot2
